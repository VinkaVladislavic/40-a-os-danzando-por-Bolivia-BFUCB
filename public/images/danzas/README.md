# Fotografías del programa

Cuando estén disponibles, guardar aquí las fotografías del Ballet usando nombres descriptivos, por ejemplo:

- `chovena.jpg`
- `taquirari.jpg`
- `macheteros.jpg`
- `tarqueada.jpg`
- `pujllay.jpg`

Después se puede asignar la ruta ` /images/danzas/nombre.jpg ` a cada danza en `src/data/program.js` y mostrarla en el modal.

La aplicación incluye por ahora espacios visuales de reemplazo; no se han inventado ni descargado fotografías de bailarines.
